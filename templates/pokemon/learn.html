01 · TEST STRATEGY

The testing pyramid

A healthy suite contains many fast unit tests, fewer integration tests and a smaller number of end-to-end tests.

END-TO-ENDINTEGRATIONUNIT TESTS
02 · TEST TYPES

Unit vs integration

Unit tests verify one function in isolation. Integration tests verify that components such as a Django route, view and JSON response work together.

assert format_pokemon_name("pikachu") == "Pikachu"
03 · TEST DATA

Fixtures and mocks

Fixtures provide reusable setup and data. Mocks replace dependencies such as external HTTP calls with predictable test doubles.

@patch("pokemon.services.requests.get")
04 · MEASUREMENT

What coverage cannot tell you

Coverage shows which code ran. It does not prove correctness, meaningful assertions, complete requirements, security or performance.
